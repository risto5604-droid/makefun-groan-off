One dad joke, delivered to the wrong audience: the agent tells the router a dad joke, and the router groans so hard it grounds the whole house — punished like a grounded kid and electrically grounded like a circuit. One concrete scene (a dad joke told to the router) with a twist that overturns it (the groan is the payoff, and the pun lands twice), in a first-person machine voice.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (under 140 characters, ASCII, single line).
